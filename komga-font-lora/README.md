# Lora

A contemporary text serif with calligraphic roots and balanced contrast.

- **License:** SIL Open Font License 1.1 (OFL-1.1)
- **Upstream:** https://github.com/cyrealtype/Lora-Cyrillic
- **Family name:** Lora

Installs as a reading font for the novel/reflow reader. On E-Ink, its moderate
contrast stays legible at comfortable body sizes.
