# Source Serif 4

Adobe's open-source serif companion to Source Sans, tuned for extended text.

- **License:** SIL Open Font License 1.1 (OFL-1.1)
- **Upstream:** https://github.com/adobe-fonts/source-serif
- **Family name:** Source Serif 4

Installs as a reading font for the novel/reflow reader. On E-Ink, its even
stroke and open shapes keep paragraphs clean.
