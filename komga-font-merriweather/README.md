# Merriweather

A sturdy text serif designed for pleasant on-screen reading at small sizes.

- **License:** SIL Open Font License 1.1 (OFL-1.1)
- **Upstream:** https://github.com/SorkinType/Merriweather
- **Family name:** Merriweather

Installs as a reading font for the novel/reflow reader. On E-Ink, its large
x-height and solid weight hold up well under partial refresh.
