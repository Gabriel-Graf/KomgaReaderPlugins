# Atkinson Hyperlegible Next

A highly legible sans-serif from the Braille Institute, focused on character
distinction for low-vision readers.

- **License:** SIL Open Font License 1.1 (OFL-1.1)
- **Upstream:** https://github.com/googlefonts/atkinson-hyperlegible-next
- **Family name:** Atkinson Hyperlegible Next

Installs as a reading font for the novel/reflow reader. On E-Ink, its
unambiguous letterforms aid reading in low-contrast lighting.
